# Worm Demo — нативный веб-порт уровня 1 (Earthworm Jim 2)

Экспериментальная игра на чистом JavaScript + Canvas: уровень 1 и червяк, **без эмулятора**. Физика, анимации, оружие, враг и звук воспроизводят поведение оригинала, снятое с эмулятора (там, где точное значение не снято, оно подобрано на глаз — см. «Что приблизительно»).

Автор кода: Alexander Orel. Лицензия кода — MIT (`LICENSE`).

## Структура
| Путь | Что |
|---|---|
| `index.html` | страница, холст 320×224, экранные кнопки A/B/C |
| `css/style.css` | стили |
| `js/game.js` | вся логика: земля/стены, бег, прыжки, хлыст, стрельба, парашют, вис на лозе, птица, смерть, HUD |
| `js/audio.js` | звуковой движок (Z80 + YM2612 + SN76489) через WebAudio |
| `data/level1.js`, `data/sound.js` | карта, анимации, звуковые данные из ROM *(не в git)* |
| `assets/img/*.png` | спрайты и тайлы *(не в git)* |

## Запуск
Нужен любой статический сервер (или просто откройте `index.html`):
```
python3 -m http.server 8000   # затем http://localhost:8000
```
Звук включается после первого нажатия клавиши/касания. `M` — выключить звук.

## Управление
←/→ бег · ↓ присесть · ↑ прицел вверх · C/пробел прыжок (в воздухе C — кульбит, A при падении — слизевой парашют, B — хлыст; прыжок под колючей веткой — вис) · A/X огонь · B/Z хлыст.

## Важно про данные
`data/` и `assets/` получены из ROM, которым вы владеете, и содержат материалы правообладателей. Поэтому они в `.gitignore` и **не должны публиковаться**. В публичный репозиторий идёт только код (`index.html`, `css/`, `js/`). Чтобы игра работала, положите свои `data/` и `assets/` локально (генератор — `demo/build_demo.py` в репозитории `ejim2-web-port`, нужен ваш ROM).
Проект не связан с Shiny/Interplay/Playmates и не одобрен ими.

## Что приблизительно
Конец уровня, эффект рожка (0x43), счётчик жизней, камера, параметры ИИ птицы (радиус ~95 px, зависания 55–125 кадров, скорость занижена), окно ввода после удара (A/B со 2-й половины подскока; в оригинале — после 44 кадров).
