Клавиши: ←/→ бег, ↓ присесть, C / пробел — прыжок (в воздухе: C — кульбит, A при падении — слизевой парашют, B — хлыст; прыжок вверх под колючей веткой — вис), A / X — огонь, B / Z — удар. Личный экспериментальный проект: нативный рендер уровня и червяка из вашего ROM, без эмулятора. Игровые данные в папках data/ и assets/ — из ROM владельца, не распространять.
